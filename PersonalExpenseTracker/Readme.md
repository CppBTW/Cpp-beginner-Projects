# 💰 Personal Expense Tracker

A simple console-based Personal Expense Tracker built in C++.

This project allows users to record, organize, search, and manage daily expenses using text files for permanent storage. It was created as a learning project to improve my understanding of C++, file handling, and structured programming.

---

## ✨ Features

- ➕ Add new expenses
- 📋 View all saved expenses
- 🔍 Search expenses by serial number
- 🗑 Delete expense records safely
- 📅 Date validation
- 💾 Permanent file storage using `fstream`
- 📂 Temporary file technique for safe deletion
- 🖥 Simple menu-driven interface

---

## 🛠 Built With

- C++
- File Handling (`fstream`)
- String Streams (`stringstream`)
- Windows Console API
- Standard Template Library (STL)
